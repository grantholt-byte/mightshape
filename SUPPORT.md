# Support

For installation problems, bugs, or usage questions, open a
[GitHub issue](https://github.com/grantholt-byte/design-council/issues). Include:

- Design Council version and platform (OpenAI/Codex or Claude Code);
- installation method and relevant CLI version;
- a minimal prompt or reproduction sequence; and
- the observable result and expected result.

Remove confidential project material, participant data, credentials, study links, and personal
information before posting. Public issues are not an appropriate channel for sensitive research
content.

For a security vulnerability, use
[private vulnerability reporting](https://github.com/grantholt-byte/design-council/security/advisories/new)
instead of a public issue. See [SECURITY.md](SECURITY.md) for scope and response guidance.

Design Council is free, open-source software provided under the MIT License. Support is
best-effort; no paid support tier or service-level agreement is offered.
