# Licensing decision

The repository uses the MIT License for the V1 plugin source. MIT is simple,
widely recognized by both plugin ecosystems, and permits public, commercial, and private use.
MightShape itself is currently free under the owner decision recorded in
`docs/MONETIZATION.md`; the license does not create a paid offering.

The tradeoff is material: MIT also permits redistribution and derivative plugins, subject
to preservation of the notice. It does not grant trademark rights, protect the MightShape
name, require improvements to be shared, or prevent competitors from using the code.

V1 retains MIT as the best fit for low-friction plugin adoption. Before a future release, the
owner may still revisit:

1. whether an explicit trademark policy is needed for the MightShape name;
2. whether a future release should use Apache-2.0 for an explicit patent grant;
3. whether any future operated service requires separate qualified legal review.

V1 recipients receive this version under MIT. Changing a future release's
license would not revoke rights already granted for versions distributed under MIT.
